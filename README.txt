Local preview
Keep the three files together and open index.html in a browser.
No dependencies, installation, or build step are required.

GitHub Pages deployment
1. Create a public repository named KiLLKiSSJUDE706.github.io.
2. Upload index.html, style.css, and script.js to the repository root.
3. Commit the files to the main branch.
4. Open Settings, then Pages.
5. Select Deploy from a branch, main, and /(root), then Save.
6. Wait for deployment and open the published URL shown in Pages settings.
7. Save screenshots of the published page and deployment status.
